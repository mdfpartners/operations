# Project Instructions

## Time Zone
All requests from the user are in **Central Time (CT)** (UTC−6 CST / UTC−5 CDT). When interpreting dates like "last night," "yesterday," or "today," always use Central Time — not the server/UTC clock. The server runs UTC, so late evenings CT (e.g. 8 PM CT) will appear as the next calendar day in UTC. Always confirm the CT date before pulling or reporting data.
